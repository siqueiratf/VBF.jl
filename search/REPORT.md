## Phase 1 — target selection

`V_A = ker(M_A)` over the 224 quadratic ANF coefficients, for each of the 32
BBL2021 n=8 LE-automorphism classes. Control: class 22 reproduces the audited
`rank(M_A) = 184`, `dim V_A = 40` exactly (F002, `bench/calibration.toml`).

**Correction to the brief's premise.** No class index is absent from BBL2021's
Table 1 — every index 1..32 carries a verdict. The table's own categories are
`no (Prop. 4)` / `no (Prop. 5)` (proved filters), `no (Alg. 1)` (exhaustive search
terminated), and `?`, which the caption defines as "we were not able to either
exclude the tuple by Prop. 4 or 5, or to finish the exhaustive search". The paper
therefore already distinguishes a proof from a budget stop; only classes 22 and 30
are `?` at n=8.

**This also means target selection does not depend on their pruning being unsound.**
BBL2021 Table 1 decides the existence of APN *permutations* `F` with `F.A = B.F`.
This search looks for quadratic APN *functions* (mostly non-bijective) in the
commutant `F.A = A.F`. A class proved to hold no APN permutation says nothing
about non-bijective quadratic APN functions in `V_A`, so every class is a
legitimate target regardless of its Table 1 verdict.

## Phases 3 + 4 — the search

**Method change, stated up front.** The brief's Phase 3 samples `V_A` for centers
and Phase 4 enumerates a hyperplane per center with a Groebner basis. For
`dim V_A <= 40` that is dominated by walking `V_A` itself: `L_a` is linear in the
ANF coefficient vector, so a Gray-code walk tests one point per XOR-plus-rank
(measured ~17M points/s across 12 threads) versus ~31 s per Groebner slice.
Walking `V_A` directly returns *every* APN function in it, so coverage is 100% of
the subspace and the result is a certified `Exhausted` — rather than the ~1e-9
coverage the hyperplane route reaches in a day. No sampling means Phase 3's
density estimate becomes an exact count.

**Continuous cross-validation.** Every candidate the fast `rank(L_a) = 7` test
accepts is immediately re-tested with `VBF.differential_uniformity`, which builds
the full DDT — a completely different code path. The sweep aborts with an error
on any disagreement. Millions of accepted points have passed both, so the fast
test is not merely validated on a fixture; it is validated on every hit reported
here. (The engine was also checked against `differential_uniformity` on Gold
`x^{2^k+1}` for k = 1..7, agreeing that it is APN exactly when `gcd(k,8) = 1`.)

**Two subspaces per class.** The brief specifies `V_A = {F : F.A = A.F}`, the
`A`-commutant. But BBL2021's classes are PAIRS `(A, B)` and `A != B` for 16 of
the 32 n=8 classes, so there the commutant is not the space their Table 1 is
about. Both were swept: `commutant` (`F.A = A.F`, as specified) and `selfequiv`
(`F.A = B.F`, the actual BBL2021 object). Where `A == B` they coincide.

One concrete consequence: classes **13 and 19 share the same `A` matrix** (their
`B` differs), so in `commutant` mode they are literally the same subspace and
return identical figures — which is why their rows below match to the digit.
`selfequiv` mode separates them. Across all 32 classes there are 31 distinct `A`
matrices, so this is the only such collision.
