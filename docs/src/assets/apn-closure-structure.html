About this report

The report covers one construction step (V5 extension or switching) from each published seed. Known outputs are CCZ-equivalent to a function of the published reference. New classes are absent from it by a verified CCZ invariant; some of them are also in the earlier private dataset.

For quadratic APN functions, EA and CCZ equivalence agree, so every invariant here separates CCZ classes. A shared invariant value does not prove equivalence. The nonbent signature counts the subspaces of each dimension inside the set of nonbent components; family instances are the named n = 8 functions of the Gold, Kasami, Taniguchi, BCL and Calderini–Budaghyan–Carlet constructions.
