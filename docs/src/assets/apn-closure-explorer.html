About this page

Each point is an admitted quadratic APN class; the ids are the admission order. Generation is the distance from a published seed along the first construction path that reached the class; its discoverer is the parent of that path. Rediscoveries count every construction path that reached a candidate of the class. Positions in the two × three map use the cell offset of the drawing page, so a class has the same place on both pages.
