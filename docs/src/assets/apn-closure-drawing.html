About this drawing

Each node is an admitted quadratic APN class, drawn by its invariants and not by the search order. x is the number of 2-dimensional subspaces in the nonbent component set; y is the number of 3-dimensional nonbent subspaces: the axes of the structure report. A fixed affine map places them: x = (two − 320)/140, y = (three − 80)/100. Classes with the same pair share a cell; inside it, each class has an offset taken only from its LUT SHA-256.

So a class has the same position in every snapshot, subset or superset, and a redraw of the same data gives the same picture. Positions show invariants; nearby classes are not claimed to be equivalent. Edges are the observed V5 (solid) and switching (dashed) constructions; by default only the selected class's edges are drawn.
