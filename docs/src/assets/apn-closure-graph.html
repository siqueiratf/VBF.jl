About this graph

Each node is an admitted quadratic APN CCZ class. Solid directed edges record V5 constructions; dashed directed edges record switching neighbours. Arrowheads appear on the selected neighbourhood. Repeated witnesses share an edge; same-class returns are listed in the node details.

These are observed relations. Missing edges and separated components can change as the search progresses. Positions are a deterministic projection of graph distances, with components packed separately; visual proximity is not an equivalence claim.
