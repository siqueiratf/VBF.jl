# Reproduction artifacts

The runner and analysis code live in [VBFRepro](../../packages/VBFRepro/README.md).
This directory holds local execution evidence and derived datasets:

- `runs/<paper>/<run>/`: parameters, source hashes, timestamps, exit status,
  stdout and stderr from an isolated reproduction process.
- `analysis/reproductions/`: paper assessments, catalog/corpus comparisons and
  invariant studies generated by the analysis commands.
- `analysis/performance/`: consolidated performance datasets and exports.
- `analysis/archive/`: original outputs from the retired root `analysis/` tree.
- `archive/`: historical scratch artifacts retained for traceability.

Generated artifacts are ignored; original tracked analysis datasets remain tracked
at their relocated paths. Historical provenance describes its original execution
and is preserved without rewriting paths or source identities.

Original copyrighted paper inputs and existing experiment results remain beside
their standalone reproduction under `packages/VBFRepro/papers/<year>/<id>/`.
They retain the paper's ignore rules and require a separate backup or distribution
agreement; Git alone does not preserve ignored local files.
